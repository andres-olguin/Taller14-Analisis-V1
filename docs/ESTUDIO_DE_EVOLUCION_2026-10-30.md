# Propuesta de evolución y demo — Taller14-Analisis-V1

**Estado:** hipótesis de producto/estudio; no modifica la finalidad original ni acredita demanda. **Fecha:** 2026-10-30.

## Propósito
TSP Visual Baseline. **Público objetivo:** Estudiantes de algoritmos. **Diferenciación por validar:** Comparación transparente de fuerza bruta y costos de rutas.

## MVP propuesto
- Landing demostrativa con explicación, alcance, ejemplos y estado real.
- Recorrido visual de las funcionalidades actuales; usar datos simulados rotulados si no hay backend.
- Medición de utilidad mediante entrevistas y pruebas de tareas con potenciales usuarios de Chile y México.
- Matriz de competidores, precios y evidencia antes de afirmar unicidad o fijar tarifas.

## Protocolo de implementación
Frontend propio, accesible, responsive; publicar mediante GitHub Pages si derechos, privacidad y plan lo permiten; enlace comprobado en README y About. Validación de inputs, autorización de rutas, CORS restrictivo, sesiones y tokens seguros, rate limits, manejo de errores sin filtración, dependencias y secretos, RLS si aplica. Pruebas de flujo y revisión de licencias. Registrar actividad real en GitHub; no simular commits diarios. Presupuesto y métricas sin inventar ingresos. No publicar información confidencial o de terceros.

## Condición de cambio
Para proyectos académicos y de clientes, preservar código, autores y propósito original. Cualquier pivot comercial será proyecto derivado con licencia y titularidad verificadas.
