Transparencia técnica
El algoritmo se ejecuta localmente en JavaScript, sin enviar información a servidores. Es una adaptación didáctica independiente del código fuente original; no se afirma que ejecute directamente los programas de Python, Java o C del repositorio.
Los datos de ejemplo son sintéticos. No se requieren cuentas ni credenciales. Antes de uso productivo deben agregarse pruebas automatizadas, evaluación de accesibilidad y revisión de seguridad.
